# Identity for a graphic

Read when the product brief's surface is a graphic. Everything in `SKILL.md` holds except what is said here. A piece counts as a screen wherever the skill says screen.

Nothing about the identity changes: the same options, one refinement, the same board. Only the size of a capture does.

- **Capture at the format.** The chosen piece, `first.html`, is built at the format's working size (see the direction's graphic reference). Every `--clip 0,0,1440,900` in this skill is `--clip 0,0,<width>,<height>` of that size. The board (`design-identity.html`) is its own page and is captured as the skill says.
- **Contrast** is checked as usual, at the level in the design brief.
