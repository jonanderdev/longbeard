# DESIGN.md

The project's `DESIGN.md` is the look.

Read it before writing UI. Use its color, type, spacing, and components the way that file states them.

If the project has no `DESIGN.md`, ask which reference to follow. Write that file only when they want one. Leave brand catalogs out of the repo. Leave a second visual system out when one already exists.
