# The second eval board

Seven pictures of web pages and posters, made for this eval. Each takes its composition, type, spacing and colour from a starred card on a private art-direction board, rebuilt here with our own words, fictional names, Google Fonts close to the originals and the photographs below. No original design or image is included, and the code that drew them is not kept: these JPEGs are the fixture. The brief and the answers' other stops are the first fixture's, so a run on this board differs from one on `fixture/` only in its references.
